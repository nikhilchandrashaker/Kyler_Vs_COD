# 🎮 Kyler Murray vs. The Double XP Weekend

A tongue-in-cheek sports-analytics side project: does Kyler Murray's on-field
performance look any different during weeks with a **Call of Duty launch** or
**Double XP weekend**, compared to a normal week?

Short answer: **statistically, basically no** — but the win/loss split is a
fun red herring. Full breakdown below.

## Why this exists

Every fall, some corner of NFL Twitter revives the joke that Kyler Murray
plays too much Call of Duty. This project takes that joke and runs actual
numbers on it, for fun — not to make any real claim about his habits,
routine, or preparation.

## Data sources

| File | Contents | Source |
|---|---|---|
| `data/kyler_murray_2024_gamelog.csv` | Murray's full 2024 regular-season game log (17 games) — completions, attempts, yards, TDs, INTs, passer rating, result | [StatMuse](https://www.statmuse.com/nfl/player/kyler-murray-27610/game-log?seasonYear=2024) |
| `data/gaming_events_2024.csv` | Verified Call of Duty: Black Ops 6 launch window + every announced 2024 Double XP weekend | [PC Gamer](https://www.pcgamer.com/games/call-of-duty/black-ops-6-release-date-time/), [Wikipedia](https://en.wikipedia.org/wiki/Call_of_Duty:_Black_Ops_6), [GameWatcher](https://www.gamewatcher.com/news/call-of-duty-black-ops-6-double-xp-weekend-events), [Game Rant](https://gamerant.com/call-of-duty-black-ops-6-next-double-xp-event-date-december-2024/), [Game8](https://game8.co/games/Call-of-Duty-Black-Ops-6/archives/490234) |

2024 was chosen because it's the only season in Murray's career that overlaps
with a brand-new mainline Call of Duty launch (Black Ops 6, Oct 25, 2024)
plus a full slate of announced Double XP weekends.

## Methodology

1. Every Murray game in the 2024 regular season is tagged as either:
   - **Gaming Week** — game day fell inside a CoD launch/Double XP window,
     or the day immediately after one ended (to catch the "played all
     weekend, game Sunday/Monday" case)
   - **Regular Week** — everything else
2. Per-game passing stats are averaged within each bucket.
3. No adjustment is made for opponent strength, game script, injuries, or
   literally anything else that actually explains NFL performance. This is
   a bit, not a study.

Run it yourself:
```bash
pip install pandas matplotlib
python3 analyze.py
```

## Takeaway

On raw passing efficiency, Murray was actually **slightly worse** by every
rate stat during gaming weeks — lower rating, fewer yards, fewer TDs. If
anything, that cuts against the "he's out here grinding Prestige levels
instead of the playbook" joke, since the dip is small and the sample is tiny.

The one number that jumps out is the **win rate**: 4-1 in gaming weeks vs.
4-8 the rest of the season. But that's almost certainly noise/team context,
not Murray — Arizona simply won more of the games that happened to fall in
these particular five weeks (including a statement road win over Miami the
week Black Ops 6 dropped). With n=5, one flipped result swings that
percentage by 20 points.

## Honest caveats (the "please don't cite this in a real argument" section)

- **n=5 gaming games.** This is not a statistically meaningful sample size.
- No causal mechanism is implied or should be inferred — this doesn't say
  anything about whether Murray plays video games, when, or how much.
- Double XP weekend dates are set by Activision marketing decisions, not
  randomly assigned, so there's no controlled comparison here.
- Passer rating swings for lots of reasons (opponent pass defense, weather,
  injuries, game script) that this project doesn't account for at all.

This is a for-fun data project, not a scouting report.
